# HTML Presentation Skill

一套内容中立的 HTML 演示制作与协作技能，适用于研究汇报、产品介绍、项目提案、工作报告、课程和故事分享。

HTML 是主要展示载体；按任务制作 PPTX、PDF 或离线网页。Reader、Editor、多语言和云端发布按需要启用，不要求每个项目具备所有功能。

## 它帮助做什么

- 先理解整场表达，再组织逐页内容，避免例子与细节带偏重点。
- 在视觉打样前，用简短 Narrative 检查 storyline、重复内容、缺失台阶与页间分工。
- 保留主张背后的理由、必要前提和概念区别，同时控制每页理解负担。
- 分清主展示、现场短延伸、Reader 常显解释与可选深入；内容决定交互。
- 用少量真实代表页验证视觉、操作及已选编辑能力，再扩展制作。
- 明确保存、发布、权限、版本与接续，验证实际使用路径。

## 安装与使用

技能目录是 [`html-presentation/`](html-presentation/)，入口为 [`SKILL.md`](html-presentation/SKILL.md)，支持文件需一并保留。

在 Codex 中可请求：

> 帮我安装 https://github.com/Jack-Fang-618/html-ppt-skills 仓库中的 html-presentation 技能。

也可以将整个 `html-presentation` 目录复制或链接到本机 Codex 的技能目录（通常是 `~/.codex/skills/`）。已有同名技能时先比较版本，不直接覆盖人工修改。重新加载技能或开启新会话后使用 `$html-presentation`。

例如：

> 使用 $html-presentation，根据我的提案和讨论记录制作 HTML 演示。先整理逐页内容与 Narrative，再用少量代表页打样。

已有作品也可以只修改某页、交互或布局，不必每次重跑完整流程。

## 六个阶段

1. 从当前状态开始：理解材料用途、受众、当前版本与实际需求。
2. 形成可评议的表达内容：整理主线、逐页职责、Narrative 与内容分层。
3. 在真实项目里设计和打样：验证代表性页面的构图、密度、素材与操作。
4. 收拢依据，完整制作与迭代：按反馈意图修订，保护已有效内容和人工编辑。
5. 检查实际成果，再交给人判断：核对表达任务、真实渲染与使用序列。
6. 发布、输出并保证可接续：交付所选格式，记录状态、修改与恢复通路。

阶段支持往返与局部接续，不是每次都要填写的固定审批表。

## 模式、语言与输出

- **Presentation**：现场主展示，可有短的页内延伸。
- **Reader（可选）**：独立阅读与深入探索，不要求每页都有长篇展开。
- **Editor（可选）**：修改已支持对象的工作环境，不是第三份独立内容。
- **多语言（可选）**：同时采用简体、繁体和英文时，默认简繁文字与布局联动，英文独立维护；允许地区差异与局部例外。
- **PPTX／演示 PDF**：默认只交付主展示，不带 Reader、Editor 或网页导航；需要阅读材料时再选择备注、附录或独立细读 PDF。核心交互转成有意义的静态内容。

## 能力范围

这是供 agent 使用的工作方法与参考包，**不内置网页模板、通用编辑器、云端服务或一键导出引擎**。agent 需根据项目和当前工具实现所选能力，并验证真实产物。

PPTX 的编辑程度由对象转换和实际验收决定，不能把整页截图称为可编辑文字。仅编辑已有独立 `.pptx` 时，应使用对应的演示文稿工具。

具体课程、品牌、页数、风格和托管平台不作为固定默认。新任务要求优先，不把历史项目的全部功能套到每份演示上。
